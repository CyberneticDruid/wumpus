# wumpus
The classic game, ported to multiple languages, for science!

The original "Hunt the Wumpus" game was written by Gregory Yob in 1973. It was the first exploration game to use a non-grid worldmap, distinguishing it from earlier grid-oriented games such as Trek and predating even 1977's Colossal Cave Adventure.

wumpus.c ported from BASIC by [Eric S. Raymond](http://www.catb.org/~esr/wumpus/) (BASIC source in the comments)
